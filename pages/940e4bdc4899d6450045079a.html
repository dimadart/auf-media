НАСА создало эпичный марсианский внедорожник

Андрей Янченко
журналист

Американское управление по аэронавтике и исследованию космического пространства презентовало восьмиметровый автомобиль для поездок по Марсу. Внедорожник показали в рамках научного фестиваля Summer of Mars. 

 

Он поделен на два отсека: один — для водителя, второй — для научного оборудования. Автомобиль оснащен шестью 50-дюймовыми колесами. Он сможет разгоняться до 110 километров в час, но по Красной планете, по словам разработчиков, будет курсировать со скоростью 25 километров в час. 

 

Внедорожник напоминает транспорт одного из главных борцов с преступностью — Бэтмена. А все потому, что его разработали братья Паркеры, которые создают дизайн техники для фантастических фильмов (кибермотоциклы для ремейка “Трона” — их рук дело). 

 

Будет “космический бэтмобиль” использоваться для поездок по Марсу или останется аттракционом на научных фестивалях и выставках, пока не известно.
